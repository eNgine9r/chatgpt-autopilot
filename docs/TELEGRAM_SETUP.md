# Сповіщення Telegram на телефон

Autopilot використовує Telegram лише для вихідних сповіщень. Бот не приймає команди з Telegram.

## Безпечне налаштування

На Raspberry Pi, у каталозі Autopilot:

```bash
npm run telegram:setup
```

Команда:

1. запитує токен бота через приховане введення в терміналі;
2. перевіряє бота через Telegram `getMe`;
3. за потреби просить відкрити бота й надіслати `/start`;
4. знаходить найновіший приватний чат через `getUpdates`;
5. зберігає `TELEGRAM_BOT_TOKEN` і `TELEGRAM_CHAT_ID` лише у локальному gitignored `.env`;
6. встановлює для `.env` права `0600`;
7. надсилає одне тестове сповіщення.

Токен ніколи не виводиться на екран і не записується в журнали проєкту.

Після успішного тесту перезапустіть supervisor:

```bash
systemctl --user restart chatgpt-project-autopilot
curl -fsS http://127.0.0.1:8765/health
```

У відповіді health має бути `"telegram":true`.

## Український профіль бота

Щоб встановити українську назву, короткий опис і повний опис Telegram-бота з уже збереженим локальним токеном:

```bash
npm run telegram:localize
```

Команда не виводить токен і не додає Telegram-команди або віддалене керування.

## Створення бота

Створюйте окремого бота через офіційний Telegram BotFather. Не використовуйте секрети інших production runtime без окремого явного погодження.

Ніколи не вставляйте токен бота в GitHub, source-файли, Issues, Pull Requests, історію чатів або журнали.
